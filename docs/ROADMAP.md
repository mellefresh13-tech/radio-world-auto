# Сопровождение проекта

Обновлено: 2026-11-10.

## Текущие приоритеты

1. Поддерживать стабильность воспроизведения на автомобильных и мобильных устройствах.
2. Сохранять надёжность обновления и публикации каталога.
3. Поддерживать актуальность Android, Python и GitHub Actions зависимостей.
4. Выполнять автоматические проверки для каждого изменения и ручную проверку release APK перед распространением.
5. Синхронизировать документацию, публичную политику конфиденциальности и Google Play Data safety с фактическим поведением приложения.

## Правила изменений

- Новые функции добавляются отдельными небольшими задачами.
- Исправления не должны включать несвязанные изменения интерфейса, каталога или CI.
- Изменения, затрагивающие воспроизведение, проверяются на целевых устройствах.
- Release APK создаётся отдельным workflow; обычные изменения main не должны запускать лишние релизные сборки.
- `catalog-data` поддерживается workflow и не используется как ветка разработки приложения.
- Изменения Firebase SDK, Analytics events, Crashlytics или настроек сбора требуют обновления privacy policy, технической документации и Google Play Data safety disclosures.

## Перед публичным распространением

- Проверить публичную политику конфиденциальности и убедиться, что она размещена по URL, который будет указан в Google Play Console.
- Перепроверить Data safety form по текущим версиям Firebase Analytics и Crashlytics и по фактическим настройкам SDK.
- Проверить применимые требования к согласию и раскрытию данных в странах, где приложение будет доступно.
- Собрать release APK/AAB с актуального main и пройти ручной QA на целевых устройствах.

## Планирование

Новые продуктовые функции, платформенная интеграция и изменение схемы публикации не считаются согласованными только потому, что упомянуты в старых заметках или обсуждениях. Их следует добавлять в план после отдельного решения владельца проекта.

Этот документ намеренно содержит только действующие направления сопровождения, а не историю завершённых экспериментов и отклонённых решений.
