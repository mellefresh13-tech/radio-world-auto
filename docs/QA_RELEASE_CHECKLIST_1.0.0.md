## Как отмечать результаты

- **P0** — критично для релиза; выпуск блокируется до прохождения или формального решения.
- **P1** — важная функциональность.
- **P2** — редкий сценарий или дополнительная проверка.
- Отмечать PASS только после проверки фактического результата. Если сценарий неприменим к устройству — N/A.
- Для каждого FAIL записать устройство, шаги воспроизведения, ожидаемый и фактический результат, а также скриншот/видео и логи, если доступны.
