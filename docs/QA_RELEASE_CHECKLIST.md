# Чек-лист QA релизной сборки

Этот чек-лист используется для проверки конкретного APK-кандидата. Отмечайте пункт только после фактической проверки на устройстве. Результат CI не заменяет ручной smoke test.

## Установка и запуск

- [ ] APK устанавливается без ошибок.
- [ ] Приложение запускается и открывает основной экран.
- [ ] Обновление поверх предыдущей версии устанавливается с сохранением пользовательских данных.
- [ ] Приложение корректно запускается после принудительного закрытия и повторного открытия.

## Каталог и поиск

- [ ] Каталог загружается при первом запуске.
- [ ] Ранее загруженный каталог доступен при временном отсутствии сети.
- [ ] Ручная проверка каталога показывает понятный результат.
- [ ] Просмотр стран и открытие списка станций работают.
- [ ] Поиск обновляет результаты во время ввода.
- [ ] Длинные названия и пустые результаты отображаются корректно.
- [ ] Избранное и недавно прослушанные станции сохраняются.

## Воспроизведение

- [ ] Станция запускается и звук воспроизводится.
- [ ] Play/Pause работает на экране и через системные медиаконтроллеры.
- [ ] Переключение станций и случайный выбор работают.
- [ ] Название станции и доступные метаданные отображаются корректно.
- [ ] При временном обрыве сети приложение корректно восстанавливает состояние.
- [ ] Недоступный поток не блокирует дальнейшее использование каталога.
- [ ] Поведение после сворачивания и закрытия приложения соответствует ожидаемому.

## Интерфейс и настройки

- [ ] Проверен автомобильный вариант интерфейса.
- [ ] Проверен телефон в портретной и альбомной ориентации.
- [ ] Проверен планшет в поддерживаемых ориентациях.
- [ ] Основные элементы управления доступны и не перекрывают текст.
- [ ] Мини-плеер открывает экран текущего воспроизведения при нажатии на его основную область.
- [ ] Play/Pause и Favorite в мини-плеере работают независимо.
- [ ] Тема, язык и размер текста применяются и сохраняются.
- [ ] Настройка удержания экрана включённым работает.
- [ ] Настройка анимации применяется корректно.

## Release и подпись

- [ ] Android unit tests завершились успешно.
- [ ] Lint завершился успешно.
- [ ] Release APK собран без ошибок.
- [ ] Проверка постоянного сертификата подписи завершилась успешно.
- [ ] APK подписан постоянным ключом, если предназначен для обновления существующей установки.
- [ ] APK из проверенного workflow artifact совпадает с APK, установленным на устройстве.

## Итог

- Результат: PASS / FAIL / BLOCKED
- Найденные дефекты:
- Решение о выпуске: GO / NO-GO

Не отмечайте релиз как полностью проверенный, если остались непройденные обязательные сценарии или APK на устройстве отличается от проверенного artifact.
