## Установка и запуск

- [ ] APK устанавливается без ошибок.
- [ ] Приложение запускается и открывает основной экран.
- [ ] Обновление поверх предыдущей версии устанавливается с сохранением пользовательских данных.
- [ ] Приложение корректно запускается после принудительного закрытия и повторного открытия.

## Каталог и поиск

- [ ] Каталог загружается при первом запуске.
- [ ] Ранее загруженный каталог доступен при временном отсутствии сети.
- [ ] При отсутствии интернета приложение не обещает офлайн-воспроизведение: каталог доступен из кэша, но эфир не запускается.
- [ ] Ручная проверка каталога показывает понятный результат.
- [ ] Просмотр стран и открытие списка станций работают.
- [ ] Поиск обновляет результаты во время ввода.
- [ ] Длинные названия и пустые результаты отображаются корректно.
- [ ] Избранное и недавно прослушанные станции сохраняются.

## Воспроизведение

- [ ] Станция запускается и звук воспроизводится.
- [ ] Play/Pause работает на экране и через системные медиаконтроллеры.
- [ ] Переключение станций и случайный выбор работают.
- [ ] Название станции и доступные метаданные отображаются корректно.
- [ ] При временном обрыве сети приложение корректно восстанавливает состояние.
- [ ] После отключения Wi-Fi и мобильной сети эфир прекращается/переходит в состояние ожидания; после восстановления сети выполняется предусмотренная попытка переподключения.
- [ ] На нестабильном или медленном соединении отображается понятное состояние буферизации/переподключения без ложного обещания гарантированного качества.
- [ ] Недоступный поток не блокирует дальнейшее использование каталога.
- [ ] Поведение после сворачивания и закрытия приложения соответствует ожидаемому.

## Интерфейс и настройки

- [ ] Проверен автомобильный вариант интерфейса.
- [ ] Проверен телефон в портретной и альбомной ориентации.
- [ ] Проверен планшет в поддерживаемых ориентациях.
- [ ] Основные элементы управления доступны и не перекрывают текст.
- [ ] Мини-плеер открывает экран текущего воспроизведения при нажатии на его основную область.
- [ ] Play/Pause и Favorite в мини-плеере работают независимо.
- [ ] Тема, язык и размер текста применяются и сохраняются.
- [ ] Настройка удержания экрана включённым работает.
- [ ] Настройка анимации применяется корректно.

## Обязательные проверки перед выпуском

Перед запуском release workflow:
- [ ] Изменения находятся в `main`; release workflow запускается только для `main`.
- [ ] Зафиксирован актуальный HEAD `main` (commit SHA), от которого будет собран APK.
- [ ] Для PR, вошедших в этот кандидат, успешно завершились обязательные проверки: Android unit tests, API and catalog metadata tests и Collector tests.
- [ ] Если после последних проверок в `main` появились новые коммиты, относящиеся к кандидату, проверки повторно выполнены на актуальном состоянии.

API/catalog metadata tests и Collector tests обязательны для проверки соответствующих изменений и перед публикацией обновлённого каталога. Они не запускаются внутри APK release workflow и сами по себе не являются отдельным техническим условием сборки APK, если каталог/collector/API не менялись.

## Release и подпись

Release workflow самостоятельно выполняет Android unit tests и Android lint. Unit tests обязательны и блокируют дальнейшую сборку при ошибке. Lint — необязательная диагностическая проверка: отчёт загружается в artifacts, но найденные замечания не блокируют сборку APK/AAB. Затем workflow проверяет подпись и сертификат и загружает артефакты.

- [ ] Android unit tests завершились успешно.
- [ ] Android lint report просмотрен; найденные замечания оценены отдельно. Результат Lint не является блокирующим условием релиза.
- [ ] Release APK собран без ошибок.
- [ ] Проверка постоянного сертификата подписи завершилась успешно.
- [ ] APK подписан постоянным ключом, если предназначен для обновления существующей установки.
- [ ] APK из проверенного workflow artifact совпадает с APK, установленным на устройстве.
- [ ] Установленный APK собран из того же commit SHA, который указан в данных сборки и прошёл обязательные проверки.
