# Адаптивный интерфейс

## Общий принцип

Radio World Auto поддерживает автомобильные мультимедийные системы, телефоны и планшеты. Интерфейс адаптируется к доступному экрану и ориентации устройства.

Автомобильный вариант и мобильный/планшетный вариант реализованы как отдельные UI-поверхности. Изменения одного варианта не должны непреднамеренно менять другой.

## Основные варианты

- **Автомобильный экран:** горизонтальный интерфейс с постоянной навигацией и крупными элементами управления.
- **Телефон:** компактная компоновка, рассчитанная на портретную и альбомную ориентацию.
- **Планшет:** более просторная компоновка с адаптацией списков и элементов управления под увеличенную ширину.

## Поведение интерфейса

- Основные действия воспроизведения должны оставаться доступными и легко различимыми.
- Длинные названия станций не должны перекрывать соседние элементы управления.
- Поиск должен оставаться удобным при использовании системной клавиатуры.
- Мини-плеер предоставляет быстрый переход к экрану текущего воспроизведения; его кнопки управления работают независимо.
- Размер текста и элементы управления должны оставаться читаемыми на поддерживаемых размерах экрана.

## Регрессионные проверки

При изменении интерфейса проверять:
- автомобильный экран в альбомной ориентации;
- телефон в портретной и альбомной ориентации;
- планшет в портретной и альбомной ориентации;
- поиск с открытой экранной клавиатурой;
- длинные названия станций;
- работу кнопок воспроизведения и избранного;
- переходы между списками и экраном текущего воспроизведения.

Если изменение затрагивает общие компоненты, необходимо проверить все варианты интерфейса. Для задачи, относящейся только к одному варианту, не следует без необходимости менять другой.
