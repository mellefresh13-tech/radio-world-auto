# Minimal automotive UI — initial design brief

Этот файл сохраняет исходное направление дизайна для 1920×720 touchscreen. Это исторический design brief, а не полный спецификационный документ текущей реализации. Актуальный интерфейс и ограничения описаны в UI.md, RESPONSIVE_UI.md и UI_PROFILES.md.

Исходные принципы:
- крупные touch targets;
- минимум визуального шума;
- тёмная графитовая база с одним сдержанным cyan accent;
- Player — главный экран;
- станция, трек и артист — ключевая информация;
- простое устойчивое navigation rail;
- сохранение playback, metadata, каталога, Favorites и steering-wheel controls.

Конкретные правила карточек, responsive layout, artwork/backdrop, размера иконок и sidebar следует брать из текущих source Kotlin/XML и актуальных документов UI. Не использовать этот первоначальный brief как требование откатывать реализованные и проверенные компоненты.
