# Radio World Auto

**Radio World Auto** — нативное Android-приложение для интернет-радио в автомобиле, на телефоне и планшете.

Приложение объединяет радиостанции разных стран, удобный поиск и управление воспроизведением в интерфейсе, адаптированном под разные экраны.

**Важно:** Radio World Auto — это интернет-радио. Для прослушивания эфира требуется подключение к интернету (Wi-Fi или мобильная сеть). Стабильность воспроизведения и качество звука зависят от скорости и устойчивости соединения, а также от доступности сервера выбранной радиостанции.

## Возможности

- Адаптивный интерфейс для автомобильных мультимедийных систем, телефонов и планшетов.
- Каталог радиостанций с просмотром по странам и поиском.
- Избранные и недавно прослушанные станции.
- Управление воспроизведением и отображение доступной информации о текущем эфире.
- Сохранение пользовательских данных и доступ к ранее загруженному каталогу.
- Автоматическое восстановление воспроизведения после возвращения интернет-соединения.
- Настройки оформления, языка и читаемости интерфейса.
- Ручное обновление каталога радиостанций.

## Каталог

Каталог обновляется отдельно от Android-приложения и публикуется через GitHub Pages / GitHub Raw. Приложение получает опубликованные данные и сохраняет их на устройстве для дальнейшего использования.

Для работы установленного приложения не требуется отдельный сервер приложения. При этом локально сохранённый каталог позволяет просматривать станции без сети, но не заменяет интернет-соединение для получения радиосигнала: аудио транслируется непосредственно серверами радиостанций.

## Сборка и проверки

Основная ветка исходного кода — `main`. Изменения рекомендуется вносить через pull request.

GitHub Actions выполняет:
- **Android unit tests** — обязательные модульные проверки Android-кода; повторяются при release-сборке;
- **API and catalog metadata tests** — проверки API-компонентов и метаданных каталога при изменениях соответствующих частей проекта;
- **Collector tests** — проверки подготовки каталога при изменениях сборщика и перед обновлением каталога;
- **Android Release APK** — ручная release-сборка только из `main`; Android unit tests блокируют релиз; Android lint выполняется как необязательная проверка и сохраняет отчёт, но не блокирует сборку; затем проверяются сборка и подпись;
- **Catalog snapshot** — автоматическая публикация каждые 6 часов и возможность ручного запуска; запуски сериализованы, чтобы не прерывать публикацию;
- **Catalog health check** — ручная проверка опубликованных данных каталога.

Релизный APK доступен в GitHub Actions artifact `radio-world-auto-release` после успешного запуска workflow **Android Release APK**. Для обновления уже установленного приложения используйте сборку, подписанную постоянным ключом проекта.

## Структура проекта

- `android/` — Android-приложение и тесты;
- `collector/` — сбор и подготовка данных радиостанций;
- `api/` — вспомогательные API-компоненты и импорт данных;
- `tools/` — утилиты проверки и подготовки публикации каталога;
- `docs/` — документация проекта;
- `.github/workflows/` — CI, release-сборка и публикация каталога.
