# Radio World Auto

Android-приложение с мировым каталогом интернет-радиостанций, рассчитанное прежде всего на использование в автомобиле и на сенсорных головных устройствах.

## Цель

Собрать собственный постоянно обновляемый каталог радиостанций со всех доступных стран и максимально большим количеством рабочих интернет-потоков.

Приложение не должно зависеть от одного каталога. Внешние каталоги используются как источники обнаружения, после чего станции нормализуются, объединяются, проверяются и публикуются через собственный API.

## Принципы

- Android native app, без WebView.
- Максимально простой автомобильный интерфейс.
- Крупные touch targets, читаемый текст, минимум действий.
- Основная навигация: **Страны**, **Жанры**, **Избранное**, **Поиск**.
- У станции может быть несколько потоков с автоматическим fallback.
- Рабочесть stream URL регулярно проверяется.
- Каталог и backend отделены от APK.
- Новые/исправленные станции должны появляться без выпуска новой версии приложения.
