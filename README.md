# Radio World Auto

**Radio World Auto** — нативное Android-приложение для интернет-радио в автомобиле, на телефоне и планшете.

Приложение объединяет радиостанции разных стран, удобный поиск и управление воспроизведением в интерфейсе, адаптированном под разные экраны.

## Возможности

- Адаптивный интерфейс для автомобильных мультимедийных систем, телефонов и планшетов.
- Каталог радиостанций с просмотром по странам и поиском.
- Избранные и недавно прослушанные станции.
- Управление воспроизведением и отображение доступной информации о текущем эфире.
- Сохранение пользовательских данных и доступ к ранее загруженному каталогу.
- Настройки оформления, языка и читаемости интерфейса.
- Ручное обновление каталога радиостанций.

## Каталог

Каталог обновляется отдельно от Android-приложения и публикуется через GitHub Pages / GitHub Raw. Приложение получает опубликованные данные и сохраняет их на устройстве для дальнейшего использования.

Для работы установленного приложения не требуется отдельный сервер приложения.

## Сборка и проверки

Основная ветка исходного кода — `main`. Изменения рекомендуется вносить через pull request.

GitHub Actions выполняет:
- **Android unit tests** — модульные проверки Android-кода;
- **API and catalog metadata tests** — проверки API-компонентов и метаданных каталога;
- **Collector tests** — проверки подготовки каталога;
- **Android Release APK** — ручная release-сборка, проверки, подпись и публикация APK как artifact;
- **Catalog snapshot** — периодическое формирование и публикация каталога;
- **Catalog health check** — проверка опубликованных данных каталога.

Релизный APK доступен в GitHub Actions artifact `radio-world-auto-release` после успешного запуска workflow **Android Release APK**. Для обновления уже установленного приложения используйте сборку, подписанную постоянным ключом проекта.

## Структура проекта

- `android/` — Android-приложение и тесты;
- `collector/` — сбор и подготовка данных радиостанций;
- `api/` — вспомогательные API-компоненты и импорт данных;
- `tools/` — утилиты проверки и подготовки публикации каталога;
- `docs/` — документация проекта;
- `.github/workflows/` — CI, release-сборка и публикация каталога.
