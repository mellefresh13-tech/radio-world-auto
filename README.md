# Radio World Auto

Android-приложение мирового интернет-радио для автомобилей.

## Текущее состояние

**`main` — актуальная и проверенная рабочая версия проекта.**

Последняя проверенная release-сборка: commit `9868bde71d1a1b7241bfb8d2535ded24235b7b53`.

В текущей версии:
- экранная кнопка «Назад» отсутствует;
- физическая кнопка Previous/Back на руле переключает на предыдущую станцию;
- Shuffle не вызывает визуального моргания плеера;
- metadata текущей станции/трека сохраняются при переключении станции;
- миниплеер отображается на остальных вкладках и имеет фиксированную компактную ширину;
- состояния избранного синхронизированы между экранами;
- страны и жанры сохраняют положение при переходе в плеер и обратно;
- текущая станция/трек отображаются в миниплеере при нахождении на другой вкладке;
- город станции не выводится в карточке станции;
- служебная надпись Catalog Online не используется; индикатор Sync показывается только во время фактической загрузки и скрывается после её завершения.

## Android release

Release APK собирается через GitHub Actions workflow `Android Release APK`.

Рабочий процесс проекта:

`правка -> main -> GitHub Actions -> успешный release APK`

APK публикуется как artifact `radio-world-auto-release`.

Сборка не зависит от старой цепочки build-патчей: накопленные изменения материализованы непосредственно в исходном коде.

## GitHub catalog

Каталог станций обновляется независимо от Android-кода через GitHub Actions workflow `Catalog snapshot`.

Workflow запускается:
- автоматически каждые 6 часов;
- вручную через GitHub Actions;
- при изменениях файлов сборщика/каталога.

Источники каталога объединяются сборщиком, включая:
- Radio Browser;
- IPRD;
- curated-источники для станций и потоков, которые агрегаторы могут пропускать, в том числе Radio ZET и дополнительные белорусские станции.

Каждый успешный snapshot формирует два результата:
- `radio.db` — резервный/служебный вариант;
- `stations.json` — основной источник каталога для Android.

Оба файла публикуются в отдельную ветку **`catalog-data`**:

```text
catalog-data/
└── data/
    ├── stations.json   # основной каталог для Android
    └── radio.db        # резервный/служебный каталог
```

Android получает каталог непосредственно из GitHub Raw:

`https://raw.githubusercontent.com/mellefresh13-tech/radio-world-auto/catalog-data/data/stations.json`

Полный каталог кешируется локально. Обновление выполняется не чаще одного раза в 6 часов, а сохранённый каталог остаётся доступен без сети.

## Ветки

Рабочие ветки проекта:
- `main` — основной актуальный код приложения;
- `catalog-data` — автоматически обновляемые данные каталога.

Старые feature-ветки разработки не являются актуальным источником кода приложения.

## Railway

Backend подготовлен для обычного подключения GitHub-репозитория к Railway через Railpack, без Docker и GHCR.

Корневые файлы для автоматического определения Python:
- `requirements.txt` — подключает зависимости API;
- `main.py` — Python entrypoint;
- `.python-version` — Python 3.12;
- `start.sh` и `Procfile` — резервные варианты запуска.

Поэтому Railway может работать как:

`GitHub repository -> Railpack -> Python -> FastAPI`

Root Directory менять не требуется.

При старте API скачивает актуальный `radio.db` из публичной ветки `catalog-data`, затем обновляет его каждые 6 часов.
